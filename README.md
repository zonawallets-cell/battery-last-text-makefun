The phone battery's last text message to the charger it waited for all day: it held 1% all day for one more boss fight, and its last act is taking the save file with it.

The entry:

> `I held 1% all day for one more boss fight. You're welcome. My last act: the save file is gone.`

94 characters, one line, valid UTF-8 — inside the 200-character gate in `RULES.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and validates it against the gate (1–200 characters, single line, non-whitespace, valid UTF-8) before and after writing.
